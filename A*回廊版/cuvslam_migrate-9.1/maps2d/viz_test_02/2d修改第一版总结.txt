二、使用方法
1. 生成地图包(一次性导出 + 建栅格):


cd ~/cuvslam_migrate-9.1
./run_map2d_builder.sh \
  --map-dir ./orbbec/viz_test_02 \
  --extractor /home/amov/cuVSLAM-main1/cuVSLAM-main/build_jetson/bin/map_extractor \
  --output ./maps2d/viz_test_02/v1 \
  --resolution 0.05 \
  --robot-radius-m 0.35 \
  --safety-margin-m 0.10
必填:--map-dir(含 data.mdb 的目录)、--extractor、--output、--resolution、--robot-radius-m、--safety-margin-m(后两者须实测后填);
可选:--ground-y <Y>(地面高度,已知才填 → 启用高度过滤生成候选障碍)、--height-min/max、--annotations <json>(人工标注)、--soft-band-m、--review(人工核验后标记)。

2. 跑测试:


cd ~/cuvslam_migrate-9.1 && venv/bin/python tests/test_map2d.py   # 12/12
3. 查看产物: maps2d/viz_test_02/v1/ 下 preview.png(点云底图,人工核验用)、grid.npz、map.json、source_map.json、annotations.json。

4. 给 A 用(未来):*


import sys; sys.path.insert(0, 'orbbec')

# 代价用 pm.cost[pm.traversable]（可通行=[0,1]，不可通行=inf）
5. 当前限制(规范内): 未配置地面高度时不自动识别障碍(全未知);未做人工标注前 reviewed=false,load_planning_map 会拒绝加载——需先现场核验地面/包络、标注自由与障碍区、--review 后才是可规划地图。
