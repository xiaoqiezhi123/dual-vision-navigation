# 高度切片与黄色边界标注

用户已确认：地面黄色长线是机器人禁止跨越的边界，可以沿线用 WallSeg 标成虚拟墙。
现有 source_map.json 只有特征点坐标、ID 和关键帧关系，没有点颜色；高度切片只能突出地面附近的特征，不能自动识别黄色。

## 坐标与地面高度

标注器读的是保存地图的全局 XYZ，单位米，不是点相对当前相机的位置。
cuVSLAM 使用 OpenCV 轴约定 X 右、Y 下、Z 前；跟踪开始时世界坐标系与 rig 坐标系重合，rig 又由相机外参决定。
参见 [cuVSLAM API：PoseEstimate / Landmark](https://nvidia-isaac.github.io/cuVSLAM/python/api.html#cuvslam.PoseEstimate)，以及本机源码 `cuVSLAM-main1/cuVSLAM-main/libs/cuvslam/cuvslam2.h`。

本工具按 `相对高度 h = 地面 Y - 点 Y` 切片。因此地面 Y 不是自动为 0，也不是当前时刻相机的离地高度。
只有在地图原点位于起始相机位置、Y 轴近似竖直向下、地面近似水平时，地面 Y 才近似等于起始相机离地高度。
例如上述条件成立且相机离地 0.70m，可先试地面 Y=0.70、相对高度 [-0.15, +0.15]m，即显示地图 Y 在 [0.55, 0.85]m 内的点。
0.70 只是例子；现有地图的地面 Y 尚未校准。旧命令 `--ground-y 0` 是人为配置，不构成地面已经归零的证据。

若地图 Y 轴与真实竖直不一致（例如起始镜头下倾且未补偿），或点云地面出现明显起伏，一条固定 Y 薄层可能截断黄线。
此版本没有自动拟合地面，也不会用全部点的 Y 中位数猜地面。需要先核验已知地面点；斜地面可在后续增加相对人工确认平面的距离切片。

## 界面操作

保存并退出旧窗口后，重新运行标注器。无需给显示高度参数也可以打开，在窗口底部试调：

1. 在“地面 Y (m)”填写地图中的地面参考 Y，在“高度下限 / 上限”填写相对该地面的范围。
2. 点 Apply 或在数值框回车，启用 Slice / 高度切片。初始下限 / 上限为 -0.15 / +0.15m；地面 Y 留空，要求人工填写。
3. 取消 Slice 恢复显示所有高度。调整参数保持当前缩放；Home 适配当前层与已完成标注的范围。
4. 取消 Red / 红点，只关闭候选着色，便于沿地面长线描虚拟墙。
5. 标题显示当前层的点数；若为 0，检查地面 Y 和范围。空白不表示可通行。

灰点与红点都受显示切片限制。红点集合仍由原先候选参数决定，显示时取它与切片的交集。
输入框编辑时，数字不会触发模式切换快捷键；非法、非有限、倒置的高度范围不会改变已经生效的显示设置。

## 命令行

正常打开、不猜地面高度，然后在界面填写：

```bash
cd /home/amov/cuvslam_migrate-9.1
./run_map2d_annotator.sh \
  --source-json maps2d/viz_test_02/v3_fixed_draft/source_map.json \
  --hide-candidates --out annotations.json
```

如果已确认地图地面 Y=0.70m，可以带参数启动（将 0.70 换成核验后的值）：

```bash
./run_map2d_annotator.sh \
  --source-json maps2d/viz_test_02/v3_fixed_draft/source_map.json \
  --display-ground-y 0.70 \
  --display-height-min -0.15 --display-height-max 0.15 \
  --hide-candidates --out annotations.json
```

| 参数 | 作用 |
|---|---|
| `--display-ground-y` | 显示切片采用的地图地面 Y，显式给出后启用切片 |
| `--display-height-min/max` | 灰色底图相对高度范围，默认 -0.15 / +0.15m |
| `--hide-candidates` | 关闭红色着色，界面可再开启 |
| `--ground-y --height-min --height-max` | 原有候选障碍参数；与显示切片参数独立 |

显示设置不写入 annotations.json，重新启动时用命令行参数或再次在界面填写。
不给原有 `--ground-y` 就没有红色候选集合，即使勾选 Red 也不会产生红点。
显示参数仅存在于标注器，不会传递给地图生成程序。

## 擦除与规划语义

- 切片不删除点、不重编号、不移动 XYZ，不改变墙线顶点的米制 XZ 坐标，也不修改 data.mdb / source_map.json。
- 开启切片时，橡皮擦只擦该高度层的原始特征点；同一 XZ 下其他高度的隐藏点不会被误擦。关闭切片则按所有高度擦除。
- 取消 Red 只是改变颜色，原先候选点若在显示高度层内仍作为灰点显示，也仍可被擦除。
- 擦除仍保存原始 ID。重新生成地图时，擦除 ID 会被排除；单纯隐藏高度不会排除任何规划候选。
- 虚拟墙不会因为切换显示高度而消失。机器人半径和安全距离由生成地图时处理，不要重复把墙线向内缩。
- 仍需标注已核验的自由区；没有点、隐藏点或擦掉点都不等于可通行。
