## 按钮说明

| 按钮 | 用途与操作 |
|---|---|
| Free / 自由区（1） | 左键点击矩形的两个对角点，第二点自动生成自由区；移动鼠标显示绿色预览，右键 / z 取消第一点。只标现场确认可通行的物理空间，机器人尺寸由生成器处理。 |
| Obstacle / 障碍区（2） | 圈出墙体、固定障碍。左键加顶点，右键闭合；合成优先级最高。 |
| Unknown / 未知区（3） | 圈出未核验区域，规划时禁止进入。 |
| RemoveCand / 剔除候选（4） | 圈选剔除自动候选障碍的范围；不删除人工障碍，也不自动把未知区变为自由区。 |
| WallSeg / 墙线段（5） | 左键依次点两个端点补一段墙；右键取消未完成的起点。 |
| Erase / 擦除特征点（6） | 按住左键拖动擦除当前显示高度层的原始特征点；其他高度隐藏点保留。下方调半径，Ctrl+Z 可恢复。 |
| Select / 选择标注（7） | 左键点击区域内部或墙线附近，青色高亮所选项。重复点击可轮换重叠项；右键或 Esc 取消选择。 |
| Delete / 删除选中（Delete） | 删除青色高亮项；没有选择时不删除任何标注。Ctrl+Z 恢复。 |
| UndoPt / 撤销顶点（z / Backspace） | 删除未闭合多边形的最后一个顶点，或取消自由矩形第一点、墙线起点。 |
| DelLast / 删除本类末项 | 在 Obstacle 模式删除最后一个障碍区，在 WallSeg 模式删除最后一段墙；其他区域模式同理。x 优先删除选中项，没有选择时删除本类末项。 |
| Undo / 撤销操作（Ctrl+Z） | 撤销一次完整标注、删除或擦除，最多保存 100 次会话内操作。 |
| Redo / 重做操作（Ctrl+Y） | 恢复刚撤销的操作；新编辑会清空重做记录。 |
| Home / 返回全图（h） | 适配当前高度层和已完成标注的范围，不改标注。 |
| Save / 保存标注（w） | 保存已完成标注和擦除 ID；未完成的自由矩形、多边形和墙线不保存。 |
| Help / 操作说明（? / F1） | 打开完整按钮说明和快捷键。 |

其他操作：中键拖动平移；滚轮缩放；Esc 取消未完成绘制；q 保存并退出。

## 撤销与删除

- **删指定障碍区或墙线**：点 Select / 7 → 左键点击目标 → 确认青色高亮 → 点 Delete / 删除选中，或按键盘 Delete。可以删除本次新画的，也可以删除重新加载的旧标注。
- **多个标注重叠**：优先选靠近点击位置的边界；在同一点重复点击，可以轮换选择重叠的标注。墙线按屏幕像素判定，放大缩小后都能点选。
- **删本类最后一项**：先切换到 Obstacle 或 WallSeg，再点 DelLast。不会因为另一类标注画得更晚而误删另一类。
- **撤销已完成操作**：Undo / Ctrl+Z 撤销最近一次完整区域、墙线、删除或擦除；Redo / Ctrl+Y 重做。删除列表中间的项后，撤销会放回原来的位置。
- **尚未画完**：UndoPt / z / Backspace 撤销多边形末顶点、自由矩形第一点或墙线起点；右键也可取消自由矩形第一点或墙线起点，Esc 可取消当前绘制。此类草稿顶点撤回不属于完整操作历史。
- 撤销历史只保留当前窗口内最近 100 次完整操作，关闭后不会保存历史。重新打开的旧标注仍可选中删除，并撤销这次删除。
- 删除的是人工区域或墙线，不是原始特征点；擦除特征点仍使用 Erase。完成后用 Save / w 保存。

## 自由区两点绘制

保存并重启标注器后生效：Free / 1 → 点第一角 → 移动鼠标检查绿色矩形 → 点对角完成，可以接着点下一块的两个角。
两点不能在同一条水平线或竖直线上，否则矩形没有面积；此时保留第一点，提示重新点第二点。

## 外部软件或网站能否编辑

**可以。**以下是根据官方文档作出的适配评估；本次尚未安装或接入这些工具，也没有上传地图。

| 工具 | 官方已支持能力 | 对当前任务的判断 | 尚需的转换 |
|---|---|---|---|
| QGIS（桌面） | 点/线/面编辑、顶点编辑、吸附、撤销重做、拓扑编辑。 | **更适合长期制作回廊地图**，便于调整内外墙和区域边界。 | 导出带本地 XZ 坐标关系的底图和矢量图层，导回后转为现有 JSON。 |
| CVAT / CVAT Online（网页） | 多边形编辑、折线标注；原生格式支持导出多边形、折线及标签。 | **网页方案优先考虑**，可以把自由/障碍/未知设成标签，墙体设成折线。 | 先生成俯视图和图像到地图的坐标变换；读取导出的 XML，将顶点转为米制 XZ。 |

## 接入时需要保留什么

建议流程：

```text
source_map.json
  → 无坐标轴、无白边的俯视底图 + 图像到 XZ 的变换记录
  → 外部工具编辑 Free / Obstacle / Unknown / RemoveCand / WallSeg
  → 导出矢量或标注文件
  → 转换为现有 annotations.json，并校验多边形与米制坐标
  → 原生成器重算 occupancy / clearance / traversable / cost
  → 检查地图后审核
```

- 现有 preview.png 带坐标轴、标题和边距，不宜直接用整张图的像素去反推地图坐标。应单独导出有明确坐标变换的标注底图。
- 保留原点、米/像素、图像宽高、X/Z 方向，以及源地图指纹；不要把室内本地坐标当经纬度，也不自动旋转或重新置零。
- 外部图像编辑器里的“擦除画笔/删除多边形”不等于删除 cuVSLAM 特征点。若要保持现有 Erase 功能，需要把选择区域映射回原始点 ID。
- 软件能编辑图形，不代表已经生成可通行地图；未知区、人工障碍优先级、机器人膨胀和审核继续由本工程处理。
