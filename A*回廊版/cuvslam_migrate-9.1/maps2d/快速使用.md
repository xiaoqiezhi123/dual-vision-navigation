## 2. 换地图：导出 → 标注 → 验证 → 规划

准备停止写入的新地图 `orbbec/viz_test_03/data.mdb`。下面名称按实际修改；半径、余量需按机器人核验。

```bash
TASK_MAP=viz_test_03
TASK_ROOT="maps2d/$TASK_MAP"
TASK_EXTRACTOR=/home/amov/cuVSLAM-main1/cuVSLAM-main/build_jetson/bin/map_extractor
TASK_RADIUS=0.50
TASK_MARGIN=0.00

# 导出初始草稿；没有自由区时不可通行是正常现象
./run_map2d_builder.sh \
  --map-dir "orbbec/$TASK_MAP" --extractor "$TASK_EXTRACTOR" \
  --output "$TASK_ROOT/v1_source" --resolution 0.05 \
  --robot-radius-m "$TASK_RADIUS" --safety-margin-m "$TASK_MARGIN"

# 开始标注；再次运行会恢复同一个工作文件
./run_map2d_annotator.sh \
  --source-json "$TASK_ROOT/v1_source/source_map.json" \
  --hide-candidates --out "$TASK_ROOT/annotations_working.json"

# 保存标注后生成规划草稿
./run_map2d_builder.sh \
  --map-dir "orbbec/$TASK_MAP" --extractor "$TASK_EXTRACTOR" \
  --output "$TASK_ROOT/v2_draft" --resolution 0.05 \
  --robot-radius-m "$TASK_RADIUS" --safety-margin-m "$TASK_MARGIN" \
  --annotations "$TASK_ROOT/annotations_working.json"
```

查看 `v2_draft/preview.png`，确认自由区、墙线和现场一致。按[现有 probes.json 格式](viz_test_02/audit_20260929_060638/probes.json)创建 `$TASK_ROOT/probes.json`，把坐标换成新地图通道内部的实际 XZ 坐标，再验证：

```bash
venv/bin/python orbbec/validate_map2d.py \
  --map "$TASK_ROOT/v2_draft" --probes "$TASK_ROOT/probes.json" \
  --output "$TASK_ROOT/audit_v2"
```

确认报告中 `checks` 和 `all_probe_paths_pass` 全部通过、现场核验完成后，**保持标注和参数不变**，将上面生成草稿命令的输出改为 `v3_reviewed`，末尾加 `--review`。然后启动：

```bash
./run_map2d_astar.sh \
  --map "$TASK_ROOT/v3_reviewed" --output "$TASK_ROOT/astar_routes"
```

这些变量在同一终端内有效。修改标注后需重新生成新版本；不要复用旧地图标注、擦除 ID 或任务点。

## 3. 标定与标注要点

- **地面高度**：从原始 3D 点云确认多处地面点的 Y，在标注器填写“地面 Y”，先用相对高度 `[-0.15,+0.15]m` 点 Apply 检查。公式 `h=地面Y−点Y`；地面 Y 不一定为 0，也不直接等于相机安装高度。当前无自动地面标定。
- **尺度/包络**：用现场距离核对地图米制尺度；核验机器人包络半径和安全余量，不能只为让通道通过而缩小参数。
- **Free / 1**：两次左键点矩形对角点，标已确认可走区域；相邻可通行区域应实际重叠，避免细缝。
- **WallSeg / 5**：点两个端点沿禁越黄线画墙；**Obstacle / 2** 圈有面积的障碍，左键加点、右键闭合。
- **Select / 7 → Delete** 删除选中标注；**Ctrl+Z/Y** 撤销/重做；**Erase / 6** 擦特征点，半径可调；**w** 保存。

灰色底图高度用 `display-*` 控制；`height-min/max` 控制候选红点。上述建图命令未启用自动高度候选。擦点或空白不等于自由区，必须标 Free。

## 4. 继续修改当前 v6

首次从有效标注导入到新工作文件（不要覆盖已有工作文件）：

```bash
./run_map2d_annotator.sh \
  --source-json maps2d/viz_test_02/v6_reviewed/source_map.json \
  --annotations maps2d/viz_test_02/v6_reviewed/annotations.json \
  --hide-candidates --out maps2d/viz_test_02/annotations_next.json
```

后续恢复编辑时，**去掉 `--annotations` 那一行**，自动读取 `annotations_next.json`。修改后生成新地图包再规划；根目录 `annotations.json` 是补缝前版本。
