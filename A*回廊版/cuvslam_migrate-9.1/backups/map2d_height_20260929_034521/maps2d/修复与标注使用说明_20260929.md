## 已修复

- 标注在栅格合成前读取，擦除 ID 保留到地图包中；增加高度区间、空点云和超大范围检查。
- 合成顺序恢复为：人工障碍 > 人工未知 > 未剔除候选障碍 > 人工自由 > 默认未知。
- RemoveCand 现在剔除其多边形触及的候选栅格，恢复下层自由/未知语义；它不删除人工障碍，也不自动声明自由区。

- 自由多边形仅释放内部格，边界相交格保守保留未知，避免凹多边形缺口漏检。边界因此可能比绘制范围额外收紧一个格子。

- 地图版本默认取输出目录名；几何校验和绑定真正的 source_map.json，加载校验标注和几何文件。已审核版本不能用 --force 覆盖。

## 标注性能与操作

使用现有 NumPy、SciPy、Matplotlib；没有安装新依赖。

- 默认 auto：远处按屏幕像素合并重复显示的点，局部放大后显示全部可见原始点。仅优化显示，保存、擦除、规划坐标不降采样。
- 中键拖动使用缓存画面，松开后重新显示该视野全部数据。拖动时新露出的边缘可能暂时空白，松开即补齐。
- 橡皮擦用 KDTree 定位，连续鼠标事件之间也会擦到；笔刷局部刷新，松开后更新点云，保持当前缩放和平移。
- Ctrl+Z / Ctrl+Y：撤销 / 重做完整多边形、墙线、删除和一次擦除。z：撤销当前未闭合多边形的一个顶点。
- 1–6：Free / Obstacle / Unknown / RemoveCand / WallSeg / Erase。
- 多边形左键加顶点、右键闭合；WallSeg 左键两点一段；[ / ] 调整擦除半径。
- h 或 Home 按钮回全图；Esc 取消当前未完成绘制；w 保存；q 或关闭窗口保存已完成标注。未闭合多边形不保存。
- 默认自动恢复 --out 已存在的标注；也可以用 --annotations 指定输入文件。

启动（在本机有桌面的终端执行）：

```bash
cd /home/amov/cuvslam_migrate-9.1
./run_map2d_annotator.sh \
  --source-json maps2d/viz_test_02/v3_fixed_draft/source_map.json \
  --ground-y 0 --height-min 0.5 --height-max 5 \
  --out annotations.json
```

ground_y=0、0.5–5m 高度带沿用之前参数，仅用于显示候选障碍。若要查看全部原始点而不区分候选，可省略这三项。灰点仍显示所有高度，不代表地面。

可选 `--display-mode points` 强制原始点显示；`--display-mode density` 强制像素图显示。默认 auto 在本机比 density 更快。
