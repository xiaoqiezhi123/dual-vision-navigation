# 按钮说明、擦除半径和外部标注工具

## 本次新增

重启标注器后生效，启动脚本和标注文件格式保持兼容。

- 底部擦除半径滑块，范围 **0.05–3.00 米**，精度 0.01 米；显示的是半径，不是直径。
- 右侧数值框可输入半径并回车；无效数值或超出范围会被拒绝，并恢复原值。
- `−` / `+` 按钮和 `[` / `]` 快捷键分别缩小 / 放大半径。滑块、输入框、标题和笔刷圆圈同步。
- 可用 `--erase-radius-m 0.5` 设置启动时的半径，默认 0.30 米。
- 模式按钮和操作按钮分为两排，增加中文名称；鼠标停在按钮上时，底部显示用途。
- 点击 **Help / 操作说明**，或按 `?` / `F1`，打开完整帮助窗口。
- 输入半径数字时不会触发 `1–6` 模式快捷键。调半径本身不擦除任何点。

本机存在 Noto CJK 字体，中文显示已通过无窗口截图检查。缺少中文字体的环境会回退英文。

## 按钮说明

| 按钮 | 用途与操作 |
|---|---|
| Free / 自由区（1） | 圈出现场确认可通行的**物理空间**。左键加顶点，右键闭合。之后由生成器计算机器人尺寸膨胀。 |
| Obstacle / 障碍区（2） | 圈出墙体、固定障碍。左键加顶点，右键闭合；合成优先级最高。 |
| Unknown / 未知区（3） | 圈出未核验区域，规划时禁止进入。 |
| RemoveCand / 剔除候选（4） | 圈选剔除自动候选障碍的范围；不删除人工障碍，也不自动把未知区变为自由区。 |
| WallSeg / 墙线段（5） | 左键依次点两个端点补一段墙；右键取消未完成的起点。 |
| Erase / 擦除特征点（6） | 按住左键拖动擦除原始特征点；松开后更新点云。下方调半径，Ctrl+Z 可恢复。 |
| UndoPt / 撤销顶点（z） | 删除当前未闭合多边形的最后一个顶点。 |
| DelPoly / 删除末项（x） | 删除最后一个显示的多边形或墙线段；用 Undo 可恢复。重载后的显示顺序按标注图层排列。 |
| Undo / 撤销操作（Ctrl+Z） | 撤销一次完整标注、删除或擦除，最多保存 100 次会话内操作。 |
| Redo / 重做操作（Ctrl+Y） | 恢复刚撤销的操作；新编辑会清空重做记录。 |
| Home / 返回全图（h） | 恢复全图视野，不改标注。 |
| Save / 保存标注（w） | 保存已完成标注和擦除 ID；未闭合多边形不保存。 |
| Help / 操作说明（? / F1） | 打开完整按钮说明和快捷键。 |

其他操作：中键拖动平移；滚轮缩放；Esc 取消未完成绘制；q 保存并退出。

## 外部软件或网站能否编辑

**可以。**以下是根据官方文档作出的适配评估；本次尚未安装或接入这些工具，也没有上传地图。

| 工具 | 官方已支持能力 | 对当前任务的判断 | 尚需的转换 |
|---|---|---|---|
| QGIS（桌面） | 点/线/面编辑、顶点编辑、吸附、撤销重做、拓扑编辑。 | **更适合长期制作回廊地图**，便于调整内外墙和区域边界。 | 导出带本地 XZ 坐标关系的底图和矢量图层，导回后转为现有 JSON。 |
| CVAT / CVAT Online（网页） | 多边形编辑、折线标注；原生格式支持导出多边形、折线及标签。 | **网页方案优先考虑**，可以把自由/障碍/未知设成标签，墙体设成折线。 | 先生成俯视图和图像到地图的坐标变换；读取导出的 XML，将顶点转为米制 XZ。 |
| Label Studio（网页界面） | 图像 PolygonLabels 多边形标签，输出顶点和标签信息。 | 适合圈区域；如需墙线和按点 ID 擦除，还需另行设计对应配置或转换。 | 它的多边形坐标按图像宽高的百分比输出，必须先还原图像位置，再转为米制 XZ。 |

官方来源：

- [QGIS 矢量编辑、吸附和顶点工具](https://docs.qgis.org/3.44/en/docs/user_manual/working_with_vector/editing_geometry_attributes.html)
- [CVAT 多边形编辑](https://docs.cvat.ai/docs/annotation/manual-annotation/shapes/annotation-with-polygons/edit-polygon/)
- [CVAT 图像标注导入导出格式](https://docs.cvat.ai/docs/dataset_management/formats/format-cvat/)
- [CVAT Online](https://docs.cvat.ai/docs/products/online/)
- [Label Studio PolygonLabels 与百分比坐标](https://labelstud.io/tags/polygonlabels)

这些工具的标注输出都不是本工程现有的 `annotations.json`，也不能直接读取 cuVSLAM 的 `data.mdb` 当规划地图。本项目需要配套导出/导入适配器。

## 接入时需要保留什么

建议流程：

```text
source_map.json
  → 无坐标轴、无白边的俯视底图 + 图像到 XZ 的变换记录
  → 外部工具编辑 Free / Obstacle / Unknown / RemoveCand / WallSeg
  → 导出矢量或标注文件
  → 转换为现有 annotations.json，并校验多边形与米制坐标
  → 原生成器重算 occupancy / clearance / traversable / cost
  → 检查地图后审核
```

- 现有 preview.png 带坐标轴、标题和边距，不宜直接用整张图的像素去反推地图坐标。应单独导出有明确坐标变换的标注底图。
- 保留原点、米/像素、图像宽高、X/Z 方向，以及源地图指纹；不要把室内本地坐标当经纬度，也不自动旋转或重新置零。
- 外部图像编辑器里的“擦除画笔/删除多边形”不等于删除 cuVSLAM 特征点。若要保持现有 Erase 功能，需要把选择区域映射回原始点 ID。
- 软件能编辑图形，不代表已经生成可通行地图；未知区、人工障碍优先级、机器人膨胀和审核继续由本工程处理。
