## 2. 运行中的指令与参数修改

在**调度器终端**输入，按回车：

```text
status       查看状态、SRU 开关、当前任务点、anchor_seq
pause        暂停当前段；关闭 SRU 时须通过独立遥控停车
localize     ARRIVED 后确认并进入下一段；PAUSED/PLAN_FAILED 后重试当前目标
help         查看帮助
quit         退出当前运行
```

`force` 只跳过 ARRIVED 后本次成功重定位的偏差校验，不代替定位，不跳过规划失败。调试透传 `send nav ...`、`send slam ...` 保留；一般测试不手工拼 `segment_load` / `segment_start`。

**NavSide 交互终端**：A/F/G 停车；人工停车后需要调度器 `localize` 恢复，直接 S/D 不启动旧路径。正常行进时 S/D 切换速度模式。SLAM 窗口是日志观察窗口，在那里打字不会控制调度器。

修改后重启；两份 `nav.yaml` / `nav_pathaware.yaml` 独立加载不继承。默认使用后者；普通参数已参考原版，新项有中文说明。参数完整索引见[快速使用的参数表](分段A星接入_快速使用.md#配置与备份)。

以后继续编辑同一工作文件，去掉 `--annotations`，避免重新导入旧版本覆盖正在编辑的内容：

```bash
./run_map2d_annotator.sh \
  --source-json maps2d/viz_test_02/v6_reviewed/source_map.json \
  --hide-candidates --out maps2d/viz_test_02/annotations_next.json
```

| 操作 | 用法 |
|---|---|
| Free / 1 | 左键点矩形两个对角点，标已确认自由空间 |
| WallSeg / 5 | 左键点两个端点，沿黄色禁越边界画线 |
| Obstacle / 2 | 多边形障碍，左键加点、右键闭合 |
| Unknown / 3 | 多边形未知区，不可通行 |
| RemoveCand / 4 | 剔除自动候选，不删除人工墙、不直接变自由 |
| Erase / 6 | 左键拖动擦特征点；半径 0.05–3 m，可滑块/数值输入/方括号调节 |
| Select / 7 → Delete | 删除所选自由区、障碍或墙线 |
| Ctrl+Z / Ctrl+Y | 撤销/重做完成项、删除、擦除 |
| z / Backspace | 撤销未完成多边形末点，取消墙线/矩形首点 |
| w / Save，q | 保存；保存退出 |
| ? / F1 | 帮助；按钮下有功能说明 |

灰点按原始 ID 记录擦除，不改变剩余点的米制坐标。开 Slice 时只擦当前高度层。自由区必须标，空白/擦除不等于可走。修改标注之后必须重新生成地图包，当前 v6 不会自动更新。

若需要地面显示切片：在窗口填写**实测的地面 Y**，高度上下限先观察 -0.15/+0.15 m，Apply 启用；取消 Red 仅隐藏候选红色。也可用以下模板，将 0.70 替换为实际核验值后运行：

```bash
# 0.70 只是示例，当前地图没有已核准的地面 Y！
./run_map2d_annotator.sh \
  --source-json maps2d/viz_test_02/v6_reviewed/source_map.json \
  --display-ground-y 0.70 --display-height-min -0.15 --display-height-max 0.15 \
  --hide-candidates --out maps2d/viz_test_02/annotations_next.json
```

相对高度 h=地面Y−点Y；这是地图系地面坐标，不能直接等同相机高度。`--height-min/max` 控制候选红点，`--display-height-min/max` 才控制灰色底图切片。源点无 RGB，不能自动提取黄色。工具没有自动地面标定；现场核验尺度和高度后记录参数。
