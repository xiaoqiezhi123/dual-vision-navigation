# VIO 衔接与居中规划：修复与复测

已写入当前工程，重启后生效。上游 38 项、下游 85 项离线测试通过；没有启动真实相机或机器人，本次不能确认现场漂移已经解决。

## 改了什么

| 部分 | 当前行为 |
|---|---|
| VIO tracker | 相机线程创建和切换，主线程等到新 tracker 确认生效才发布定位结果 |
| 定位预热 | 暂停后输入 `localize`，图像和 IMU 一起恢复供数；定位前等待两线程挂起确认 |
| IMU 衔接 | VIO/定位 tracker 各自维护缓存和时间下界，每次 Track 后推进到图像时间；新 tracker 不接入长暂停前的旧 IMU |
| 成功/失败/取消 | 均安全交接、清理旧结果队列、重置局部基线，避免新旧局部坐标直接做差；人工暂停仍需调度器授权恢复 |
| 其他修正 | 暂停等待不再空转；冷却拒绝不留下 busy；释放临时定位 tracker 引用；每次新建独立配置对象 |
| A* | 增加离墙软代价，优先走净空大的区域；折线简化增加净空约束，避免重新切向墙边 |
| 15 点 | 仍是实际重定位起点 + 13 中间点 + 所选终点；保留转角、精确端点并检查全部连线，点数不足则暂停 |
| 诊断 | 增加 tracker 代次/ID、track 墙钟/当前线程 CPU 时间、IMU 等待/注册、左右图像时间差与拒绝原因 |

报告已排除跨 tracker 代次的局部坐标差；正常重建不会仅因局部原点重置就被统计为漂移。全局出口突变继续独立检查。

停车参数、5 个目标、标注和地图数据库保留。打印 Y=0，模型路径 Z=0.5，mix 编码器、5 Hz，继续沿用此前约定。

## 新报告如何判断

| 看什么 | 正常或可解释 | 需要继续查什么 |
|---|---|---|
| 第 3 节 tracker 代次表 | 恢复后有帧，对象不一致为 0；每次交接代次递增 | 有帧但对象不一致；0 帧仅代表未恢复跟踪或证据不足 |
| IMU 注册时间差 | 接受图像时末个先行 IMU 距图像不超过 20 ms | 持续拒绝图像、无有效 VIO，查采集缺口、积压和时钟 |
| 静止段局部 VIO | 在同一代次内比较，并结合真实静止时刻 | 停稳仍持续漂移/突跳；不要跨 tracker 代次比较局部坐标 |
| track 耗时 | 新日志同时有墙钟与当前线程 CPU 耗时 | 仍有长调用时结合 IMU 源时间缺口，继续查原生计算、线程调度/GIL 或 GPU 竞争 |
| 全局出口 → 接收 → SRU | 按同一源包匹配 | 原始 VIO 正常但全局异常查累积；发送正常但接收迟查收包；接收正常但推理位姿旧查下游循环 |

新鲜度检查最多等待 IMU 150 ms；超过等待仍不匹配则跳过图像。图像落后已缓存最新 IMU 超过 250 ms 也跳过。原始 `slam_*.jsonl → imu_frame_rejected` 有具体原因；这些是避免把积压数据喂入 tracker 的门槛，不代表原生采集问题已经消失。字段说明见 [位姿诊断快速使用](位姿链路诊断_快速使用_20260930.md)。

## 居中参数和效果

参数在 `config/task_nav.yaml → astar.center_preference`，已有中文注释：

| 参数 | 当前值 | 含义 |
|---|---:|---|
| `enabled` | true | false 恢复原地图代价和 0.30 m 简化；只回退规划偏好，不回退 VIO 修复 |
| `decay_length_m` | 0.8 m | 离墙代价的衰减距离，让通道内部仍有代价差别 |
| `cost_weight` | 4.0 | 越大越偏向净空大的路线，也可能更绕 |
| `simplification_tolerance_m` | 0.10 m | 简化折线允许偏离密集 A* 路线的距离 |
| `max_clearance_loss_m` | 0.05 m | 每条简化捷径相对原子路径允许损失的最小净空 |

地图硬障碍与膨胀距离不变，起终点不会自动移动；软偏好也不保证几何中线。狭窄处或靠墙端点仍会限制净空。全部参考线段检查完成才下发。每段 `route.json` 记录 `center_preference`、`min_clearance_m` 和 15 点坐标。

同一历史起终点使用正式规划器回放：

| 路线 | 原最小净空 → 新最小净空 | 原长度 → 新长度 |
|---|---|---|
| 第一段首次规划 | 0.538 → 0.891 m | 9.26 → 10.13 m |
| 第一目标前短距离重规划 | 0.842 → 0.891 m | 0.662 → 0.715 m |
| 第二段 | 0.636 → 0.814 m | 7.86 → 8.01 m |

净空是地图中机器人中心到障碍/未知区的保守距离，不是机身外壳到现场墙面的实测距离。对比图中橙色为历史路线、蓝色为正式新版，灰色不可通行，绿色越深净空越大。

已通过当前 5 个目标的预规划：第一起点取历史定位，后续以先前目标假设为起点；另有 3 条历史真实定位路线回放。每条均 15 点、端点精确、全部连线可通行。现场仍使用每次真实定位作为起点，不能把离线预规划当成整圈导航已经验证。
